# 0008. Name: truvity/session

Status: accepted, 2026-11-18 (decision E5)

## Context

The repository needs a short, public name.

## Options considered

| Option | Meaning |
| --- | --- |
| A | `session`, in the `truvity` organisation |
| B | A name that mentions OIDC or the proxy |
| C | A product-style name |

## Decision

A. The repository is `truvity/session`.

## Consequences

- The name says what the component keeps: the browser session.
- It does not tie the name to one protocol or one proxy.
- The binary, the image and the Helm chart use the same name.
